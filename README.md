# camilafarias112.github.io

Personal portfolio of **Camila Farias Amorim, Ph.D.** — Multi-omics Lead
and Computational Biologist.

🔗 **Live site:** https://camilafarias112.github.io

## About

A single-page portfolio covering my work in single-cell genomics,
multi-omics integration, translational biomarker discovery, and
AI-augmented analytical workflows in cell therapy.

## Built with

- Static **HTML5 + CSS3** — no framework, no build step
- Hosted on **GitHub Pages**
- Fonts: Inter + Playfair Display (Google Fonts)
- Altmetric badges for publication metrics

## Structure

    index.html      — the site
    style.css       — all styling
    404.html        — custom not-found page
    images/         — photos, figures, logos
    Resume_CV.pdf   — current CV

## Run locally

    python3 -m http.server 8000
    # open http://localhost:8000
